# SUIT device update

## About

This application demonstrates use of the [`ariel-os-suit`](https://ariel-os.github.io/ariel-os/dev/docs/api/ariel_os_suit/index.html) and [`ariel-os-device-update`](https://ariel-os.github.io/ariel-os/dev/docs/api/ariel_os/device_update/index.html) APIs.

This example use SUIT manifest `suit/suit-manifest-ariel.cbor` to perform a software update using either HTTP or CoAP on top of the whichever network layer is supported by the board (Ethernet-over-USB or WiFi).

After fetching and validating the update file that the SUIT manifest points to, the board will reboot and the bootloader will begin swapping the partition.

To make observation of the update more straightforward in it is recommended to use a blinky or a similar application.

## How to run

Currently this example has only been tested on the nRF52840DK.

### Create the update file

After choosing the example that should be turned into an update, the `device-update` feature needs to be enabled on `ariel-os` by modifying the `Cargo.toml`. For example with the `gpio` example, in this directory run

```sh
laze build -b nrf52840dk -C ../gpio-blinky
llvm-objcopy -O binary ../../build/bin/nrf52840dk/cargo/thumbv7em-none-eabihf/release/gpio bins/gpio.bin
```

### Generate the SUIT manifest

This example supports SUIT manifest generated by [Taylor](https://github.com/ariel-os/taylor). Taylor uses a template file and a variable file to generate the manifest.

[manifest-ariel.jinja](./suit/manifest-ariel.jinja) is the jinja template that describe the static parts of the SUIT manifest.

The file [vars-ariel.json](./suit/vars-ariel.json) is meant to be partially generated by the build system to include the correct values necessary for the final manifest. This example use this file directly for easier fine-tunning. In particular this file encodes the **URI** of the payload and its **sha256 digest**.

The manifest can be generated and be signed with

```sh
taylor --template ./suit/manifest-ariel.jinja --vars-file ./suit/vars-ariel.json -o . -k ./suit/demo-private-key.pem
```

### Run the update

First the Ariel OS bootloader needs to be flashed then the SUIT can be run. In this directory, run
```sh
laze build -b nrf52840dk -C ../../src/ariel-os-bootloader flash
laze builb -b nrf52840dk run
```

The [networking chapter] of the book contains information on how to set up networking. After networking is set up, the button 1 can be pressed to start the update.
